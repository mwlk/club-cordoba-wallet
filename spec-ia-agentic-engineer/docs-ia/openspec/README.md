# OpenSpec

Estructura generica de especificaciones dentro de `spec-ia-agentic-engineer/docs-ia/openspec/`.

```text
openspec/
+-- _templates/
+-- changes/
+-- specs/
+-- archive/
```

## changes

Trabajo activo, una carpeta por feature. Cada change es **full** (`proposal.md`+`design.md`+`tasks.md`+
`documentation.md`+`specs/`, via `/sdd-new`) o **lite** (`lite.md`+`tasks.md`, via `/sdd-new-lite`) — ver
criterio en `.claude/commands/sdd-new.md`.

## specs

Contratos estables del sistema.

## archive

Cambios cerrados con documentacion final.
