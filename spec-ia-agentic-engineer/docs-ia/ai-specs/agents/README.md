# agents

Esta carpeta contiene agentes de IA especificos del proyecto.

`spec-setup` o `/sdd-setup` debe crear al menos un agente principal, por ejemplo:

```text
spec-ia-agentic-engineer/docs-ia/ai-specs/agents/project-agent.md
```

El agente debe resumir el rol que la IA debe asumir, reglas tecnicas, checklist y comandos reales del proyecto.
